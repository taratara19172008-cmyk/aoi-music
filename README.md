# あおいミュージック AoiMusic 🎵

第三方 Apple Music 网页客户端。界面按 iOS 原版 Apple Music 复刻，功能栏在**左侧**，全部按键为液态玻璃（Liquid Glass）风格，主色调可在设置里更换。

## ✨ 功能

- 🏠 首页：热门歌曲 / 专辑 / 精选歌单（实时来自 Apple Music 曲库）
- 🔍 搜索：全曲库搜歌、专辑
- ▶️ 播放界面：照 iOS 原版布局——大封面（支持专辑**动态封面**，没有动态封面时是静态封面缓推效果）、进度条、玻璃控制键、音量、同步歌词
- 🔐 连接 Apple 账户：在设置里点「连接 Apple 账户」，在苹果官方弹窗登录（本页接触不到密码）。连接有订阅的账户后播放**完整歌曲**并可查看你的资料库/歌单；未连接时为 30 秒试听
- 🎨 设置里可换主题色（7 种预设 + 自定义），自动记住

## 🛠️ 技术说明

- 播放与曲库走 **MusicKit JS**（苹果官方网页播放 SDK）
- `config.js` 里是开发者令牌，取自苹果网页播放器的公开令牌（不是任何人的账户凭证）；它会过期（当前这枚到 2027-01），过期后重新提取替换即可
- 你的账户用户令牌只存在你自己浏览器的 MusicKit 里，不经过任何服务器、不写进本仓库

## 🚀 使用

打开 GitHub Pages 地址即可用，也可「添加到主屏幕」当 App 用（图标已按 Liquid Glass 全出血规范适配）。

本地预览：

```bash
cd aoi-music
python3 -m http.server 8000
# http://localhost:8000
```
